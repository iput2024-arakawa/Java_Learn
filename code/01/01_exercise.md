# トピック1 演習問題: 基本文法（型・変数宣言・println）

## 問題

自己紹介プログラムを作成してください。

### 要件

1. `Main` という名前のクラスを作成する
2. `main` メソッドの中で、以下の変数を宣言する
   - 名前（`String`型）
   - 年齢（`int`型）
   - 好きな数字（`double`型、小数を含む値）
   - 学生かどうか（`boolean`型）
3. `System.out.println` を使って、以下の形式で出力する

### 期待する出力例

変数に以下の値を入れた場合：
- 名前: `"花子"`
- 年齢: `21`
- 好きな数字: `3.14`
- 学生かどうか: `true`

出力：
```
名前: 花子
年齢: 21
好きな数字: 3.14
学生です: true
```

### ヒント

- 文字列の連結には `+` 演算子を使う
- 出力は1行の`println`にまとめても、複数行に分けてもよい
