# トピック2 演習問題: クラスとインスタンス

## 問題

`Student`（学生）クラスを作成してください。

### 要件

1. `Student` クラスを作成する
   - フィールド：`name`（`String`型）、`score`（`int`型）
   - コンストラクタ：`name`と`score`を受け取り、フィールドを初期化する
   - メソッド `introduce()`：名前と点数を出力する
   - メソッド `isPassed()`：`score`が60以上なら「合格」、未満なら「不合格」と出力する
2. `Main`クラスの`main`メソッドで、`Student`のインスタンスを2つ作成し、
   それぞれに対して`introduce()`と`isPassed()`を呼び出す

### 期待する動作・出力例

以下のようにインスタンスを作成した場合：

```java
Student student1 = new Student("山田", 75);
Student student2 = new Student("鈴木", 45);
```

出力：
```
名前: 山田, 点数: 75
合格
名前: 鈴木, 点数: 45
不合格
```

### ヒント

- `isPassed()`の中では、トピック1で使った`if`文の知識（Pythonの`if`と同じ考え方）が使える
- フィールド名と、コンストラクタの引数名が同じになるので`this`を忘れずに
