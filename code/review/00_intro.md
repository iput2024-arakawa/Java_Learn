# 復習トラック（書き方の勘を取り戻すための並行レーン）について

## この復習トラックの目的

久しぶりにJavaを書くときや、しばらく間が空いたときに、**新しい概念を学ぶのではなく
「もう知っている書き方をスラスラ書けるか」を確かめる**ための場所です。

`code/01`〜`06`などの本編トピックはずっと`Employee`系の題材を使ってきましたが、
同じ題材だけで復習を繰り返すと、コードの中身まで覚えてしまい「1から設計を考える」
練習にならなくなってしまいます。そこで、この`code/review/`では**毎回別の題材**
（動物園、図書館、乗り物…など）で、同じOOPの構造（カプセル化・継承・
ポリモーフィズム・インターフェースなど）を再構成する問題を出します。

`competitive/`（アルゴリズム的思考を鍛える並行トラック）と同じ位置づけで、
本編の連番トピック（`code/01`, `code/02_student`…）とは別レーンです。

## 進め方

- `code/review/`の中に、セッションごとに新しいサブフォルダを作ります
  （`code/review/01_zoo/`のように「2桁の連番＋題材名」）
- 各フォルダの`problem.md`に問題文・要件・期待する入出力例を書きます
- 本編のような座学（ステップ1の詳しい解説）は行いません。すでに学んだ内容の
  総復習という位置づけのため、`problem.md`の冒頭に**簡単な用語おさらい**
  （3〜4行程度の箇条書き）だけを添えます
- 提出コードは同じフォルダに`.java`ファイルとして作成してください
- レビューの観点は本編と同じです：
  1. 動作するか・要件を満たすか
  2. Javaらしい書き方（命名規則、アクセス修飾子の使い方など）になっているか
  3. 良い点と改善点を具体的に
  4. 模範解答例とその解説
