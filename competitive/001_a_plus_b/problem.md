# 問題001: A + B

診断1問目。標準入力の受け取り方に慣れることが主目的です。

## 問題文

2つの整数 A, B が与えられます。A + B の値を出力してください。

## 制約

- 1 ≤ A, B ≤ 10^9
- 入力はすべて整数

## 入力形式

```
A B
```

（半角スペース区切りで1行に与えられます）

## 出力形式

A + B の値を1行で出力してください。

## 入出力例

入力例1:
```
2 3
```
出力例1:
```
5
```

入力例2:
```
1000000000 1000000000
```
出力例2:
```
2000000000
```

## ヒント

- `competitive/00_intro.md`のScannerの使い方を参考にしてください
- A, Bの最大値（10^9）を考えたとき、A + Bの結果が`int`型の範囲
  （約-21億〜21億）に収まるか、一度自分で計算して確認してみましょう
