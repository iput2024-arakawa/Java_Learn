# 問題002: Range（最大値と最小値の差）

診断2問目。複数の値をまとめて受け取る処理と、ループでの集計に慣れることが目的です。

## 問題文

N個の整数からなる数列が与えられます。数列の最大値と最小値の差を求めてください。

## 制約

- 1 ≤ N ≤ 100000
- 数列の各要素は -10^9 以上 10^9 以下の整数

## 入力形式

```
N
a1 a2 a3 ... aN
```

## 出力形式

最大値と最小値の差を1行で出力してください。

## 入出力例

入力例1:
```
5
3 1 4 1 5
```
出力例1:
```
4
```
（最大値5、最小値1なので 5 - 1 = 4）

## ヒント

- N個の値をまとめて受け取るには、配列（`int[]`）や`List<Integer>`が使えます。
  `for`文で`N`回`sc.nextInt()`を呼び出して、順に格納していく形になります
- 全ての組み合わせ（ペア）を比較する必要はありません。N=100000のとき、
  もし全ペアを比較すると最大で約50億回の比較になってしまいます
  （これが「計算量」の考え方です）。1回のループで最大値・最小値を
  同時に更新していく方法を考えてみてください

同じフォルダに`Main.java`を作成して提出してください。
