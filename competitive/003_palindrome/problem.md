# 問題003: 回文判定

診断3問目。文字列操作と、比較ロジックの組み立て方を見ます。

## 問題文

文字列Sが与えられます。Sが回文（前から読んでも後ろから読んでも同じ文字列）であれば
`Yes`、そうでなければ`No`を出力してください。

## 制約

- 1 ≤ Sの長さ ≤ 100000
- Sは英小文字のみからなる

## 入力形式

```
S
```

## 出力形式

`Yes`または`No`を1行で出力してください。

## 入出力例

入力例1:
```
level
```
出力例1:
```
Yes
```

入力例2:
```
java
```
出力例2:
```
No
```

## ヒント（今回初めて使う可能性がある構文）

- `String`の1文字を取り出すには`charAt(index)`メソッドが使えます（Pythonの`s[i]`に相当）
  例：`s.charAt(0)`は先頭の1文字
- 文字列の長さは`s.length()`で取得できます（配列の`.length`はフィールド、
  文字列の`.length()`はメソッドである点に注意してください）
- 解き方は少なくとも2通り考えられます
  1. 文字列を反転させて、元の文字列と比較する（`StringBuilder`の`reverse()`が使えます）
  2. 両端から中央に向かって1文字ずつ比較していく
  どちらでも正解ですが、なぜ2通りの方法があるのか、処理のイメージを考えてみると
  今後の「計算量」の話につながります

同じフォルダに`Main.java`を作成して提出してください。
