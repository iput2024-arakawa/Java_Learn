# トピック1: Javaの基本文法（型・変数宣言・println・Pythonとの違い）

## 1. これは何か、なぜ必要か

Javaは「静的型付け言語」です。プログラムを実行する前（コンパイル時）に、
すべての変数がどんな型（数値？文字列？など）を持つかが決まっていて、
コンパイラがそれをチェックします。

これに対してPythonは「動的型付け言語」です。変数の型は実行時に決まり、
自由に別の型を代入し直すこともできます。

```python
# Python: 型を書かなくてもいい。実行時に決まる
x = 10
x = "文字列でもOK"
```

Javaでは、コンパイル時に型を保証することで、
「実行してみたら実は文字列が来ていてバグった」というミスを事前に防ぐ、
という考え方が根底にあります。これは「大規模なプログラムを複数人で安全に開発する」
というJavaの設計思想から来ています。

## 2. Javaでの書き方・構文（最小サンプル）

```java
public class Main {
    public static void main(String[] args) {
        int number = 10;          // 整数型
        double price = 19.8;      // 浮動小数点型
        String message = "こんにちは"; // 文字列型（クラス）
        boolean isActive = true;  // 真偽値型

        System.out.println(message);
        System.out.println("number = " + number);
    }
}
```

ポイント：
- `public class Main` … Javaのプログラムは必ず「クラス」の中に書く（クラスについては次のトピックで詳しく扱う）
- `public static void main(String[] args)` … プログラムの開始地点（エントリーポイント）。おまじないとしてまず覚えればOK
- `型名 変数名 = 値;` … 変数宣言には必ず型を書く
- 文の最後には `;`（セミコロン）が必須
- 標準出力は `System.out.println(...)`

## 3. Pythonとの対比

| 項目 | Python | Java |
|---|---|---|
| 変数宣言 | `x = 10` | `int x = 10;` |
| 型の指定 | 不要（動的型付け） | 必須（静的型付け） |
| 文字列出力 | `print("hello")` | `System.out.println("hello");` |
| 文末 | 改行で区切る | `;` セミコロン必須 |
| 実行の起点 | ファイルの最初から順に実行 | `main`メソッドから実行 |
| コード全体の入れ物 | 不要（関数や文をそのまま書ける） | 必ず`class`の中に書く |

「Pythonではこう書くが、Javaではこう書く」という視点で見ると：

```python
# Python
name = "太郎"
age = 20
print(name, "は", age, "歳です")
```

```java
// Java
String name = "太郎";
int age = 20;
System.out.println(name + "は" + age + "歳です");
```

なぜJavaではこのように型を明示するのかというと、Javaは
「コンパイル時に安全性をできるだけ保証したい」という言語だからです。
Pythonのような「柔軟だが実行するまでエラーに気づきにくい」設計とは
逆の思想を取っています。

## 4. つまずきやすいポイント・よくある間違い

- **セミコロン忘れ**：Java初心者の最頻出エラー。`;`を忘れるとコンパイルエラーになる
- **型の不一致**：`int number = "10";` のように、宣言した型と違う値を代入するとコンパイルエラー
  （Pythonの感覚で「文字列でも数値でも入る」と思わないこと）
- **`String`は大文字始まり**：Javaの組み込み型は`int`, `double`, `boolean`など小文字だが、
  `String`だけは大文字で始まるクラス型（これは後の「クラス」の回で理由がわかります）
- **`main`メソッドのシグネチャ**：`public static void main(String[] args)` は
  1文字でも間違えると動かない。最初は「決まり文句」として丸ごと覚えてよい
- **`+`演算子の挙動**：数値同士の`+`は足し算だが、文字列が絡むと連結になる
  （例: `"number = " + 10` → `"number = 10"`）。Pythonのように文字列と数値を
  `+`で直接つなぐとエラーになる場合がある点は要注意（Javaは自動で文字列に変換してくれる場合と、
  そうでない場合があるので、慣れるまで意識する）
